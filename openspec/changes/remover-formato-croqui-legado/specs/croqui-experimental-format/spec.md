## REMOVED Requirements

### Requirement: Import and Export functionality
**Reason**: O formato de arquivo empacotado .croqui foi descontinuado em favor do pareamento em tempo real via Live Reload (local e relay) e submissão oficial de alterações diretamente via Pull Request no GitHub.
**Migration**: A pré-visualização e testes em dispositivos móveis devem ser realizados exclusivamente através do Live Reload híbrido, e o compartilhamento ou submissão oficial deve ocorrer através do fluxo de Pull Requests.

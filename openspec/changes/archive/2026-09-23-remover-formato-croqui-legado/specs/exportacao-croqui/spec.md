## REMOVED Requirements

### Requirement: Exporting to .croqui format
**Reason**: O formato binário proprietário .croqui (ZIP com ofuscação de magic number) foi integralmente descontinuado do ecossistema Aresta.
**Migration**: Não há substituição de arquivo físico. A visualização e teste no dispositivo móvel é feita via Live Reload e o compartilhamento/versionamento é feito pelo Git / GitHub.

### Requirement: Interface de Exportação
**Reason**: O botão e diálogo de exportação para .croqui foram removidos da interface gráfica.
**Migration**: Utilizar a funcionalidade de "Conectar Celular" para testes interativos ou "Publicar" para submissão oficial no GitHub.
